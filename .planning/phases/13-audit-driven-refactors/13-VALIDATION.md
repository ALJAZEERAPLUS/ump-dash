# Phase 13 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> See 13-RESEARCH.md §Validation Architecture for detailed rationale.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | cargo test + cargo clippy + cargo-llvm-cov |
| **Config file** | Cargo.toml (workspace root) |
| **Quick run command** | `cargo test --lib` (46 lib tests; ~1s) |
| **Full suite command** | `cargo test --all-targets && cargo clippy --all-targets -- -D warnings` |
| **Shape-validation** | `make arch-lint` (grep guards — see §Shape Guards) |
| **Coverage check** | `make cov-check` (per-file floor(baseline, 5) thresholds) |
| **Estimated runtime** | ~10s test+clippy; ~45s coverage |

---

## Sampling Rate

- **After every task commit:** Run `cargo build && cargo clippy --all-targets -- -D warnings` (shape-preserving edits)
- **After every plan completion:** Run `cargo test --all-targets` + `make arch-lint`
- **After every wave:** Run `make cov-check` — confirms per-file ratchets hold
- **Before `/gsd-verify-work`:** Full suite + `make arch-lint` + `make cov-check` must all be green
- **Max feedback latency:** 60 seconds (cargo test --lib + clippy)
