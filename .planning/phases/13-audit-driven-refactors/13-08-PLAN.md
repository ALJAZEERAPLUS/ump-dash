**CRITICAL:** `crate::infra::*` imports are ONLY allowed in src/app/runtime.rs::run
(the startup/wiring function). All other src/app/*.rs files must be infra-free.
This is the classical hexagonal pattern — the main entry point is the only place
that knows about concrete adapter types.

BUT the grep guard G-01 is `! rg 'crate::infra::' src/app/` and it will fail if
runtime.rs contains these imports. Resolution options:
1. Accept that runtime.rs is the single exception — add a file-level exclusion to the
   grep guard: `rg 'crate::infra::' src/app/ | grep -v 'runtime.rs::\(run$\|main startup\)'`
2. Move adapter construction to src/main.rs — but then main.rs (outside src/app/)
   does the wiring. Cleaner. Pros: G-01 is unconditional `src/app/` = 0 hits.
3. Keep runtime.rs construction but relax the guard: `! rg 'crate::infra::' src/app/ | grep -v runtime.rs`

**Choice: Option 2 — move adapter construction to src/main.rs.** This gives the
strongest G-01 invariant and matches the classical hexagonal pattern where the
executable root is the composition root. `src/main.rs` constructs Adapters, calls
`rn_dash::app::run(terminal, adapters)`. `app::run` signature gains an `adapters: Adapters`
parameter.

### effect_runner.rs full impl

Plan 13-07 left effect_runner partially populated (mostly metro arms; other variants
had `crate::infra::*` direct calls as a temporary shortcut). This plan completes it.

Target shape per 13-PATTERNS.md:866-925:
```rust
use crate::app::adapters::Adapters;
use crate::app::effect::Effect;
use crate::domain::action::Action;
use crate::domain::ports::command_runner_port::CommandEvent;
use crate::domain::metro::MetroActivity;
use std::sync::Arc;
use tokio::sync::mpsc::UnboundedSender;

pub struct EffectRunner {
    pub adapters: Adapters,
    pub action_tx: UnboundedSender<Action>,
}

impl EffectRunner {
    pub fn new(adapters: Adapters, action_tx: UnboundedSender<Action>) -> Self {
        Self { adapters, action_tx }
    }

    pub async fn run_effects(&self, effects: Vec<Effect>) {
        for effect in effects {
            self.run_effect(effect).await;
        }
    }

    async fn run_effect(&self, effect: Effect) {
        match effect {
            Effect::ScheduleAction(action) => {
                let _ = self.action_tx.send(action);
            }
            Effect::SpawnCommand { spec, cwd, branch } => {
                let runner = self.adapters.command_runner.clone();
                let tx = self.action_tx.clone();
                tokio::spawn(async move {
                    let mut rx = runner.spawn(spec, cwd, branch);
                    while let Some(ev) = rx.recv().await {
                        let action = match ev {
                            CommandEvent::OutputLine(l) => Action::CommandOutputLine(l),
                            CommandEvent::Exited(_) => Action::CommandExited,
                        };
                        let _ = tx.send(action);
                    }
                });
            }
            Effect::DetectExternalMetro { port } => {
                let probe = self.adapters.port_probe.clone();
                let tx = self.action_tx.clone();
                tokio::spawn(async move {
                    match probe.detect_external(port).await {
                        Some(info) => { let _ = tx.send(Action::ExternalMetroDetected(info)); }
                        None => { let _ = tx.send(Action::MetroStartConfirmed); }
                    }
                });
            }
            Effect::SpawnMetro { worktree } => {
                let metro = self.adapters.metro.clone();
                let tx = self.action_tx.clone();
                let activity_tx = tx.clone();
                tokio::spawn(async move {
                    let on_activity: Box<dyn Fn(MetroActivity) + Send + Sync> = Box::new(move |act| {
                        let _ = activity_tx.send(Action::MetroActivityUpdate(act));
                    });
                    match metro.start(worktree, on_activity).await {
                        Ok(handle) => { let _ = tx.send(Action::MetroHandleReady(handle)); }
                        // NOTE: Action::MetroHandleReady is NEW — carries Box<dyn MetroHandle>
                        // update()'s MetroHandleReady arm calls state.metro.register(handle)
                        Err(e) => { let _ = tx.send(Action::MetroStartFailed(e.to_string())); }
                    }
                });
            }
            Effect::MetroHttpPost { url, body } => {
                let metro = self.adapters.metro.clone();
                tokio::spawn(async move { let _ = metro.http_post(&url, &body).await; });
            }
            Effect::KillProcess { pid } => {
                let probe = self.adapters.port_probe.clone();
                tokio::spawn(async move { let _ = probe.kill_process(pid).await; });
            }
            Effect::LoadDevices { kind } => {
                let devices = self.adapters.devices.clone();
                let tx = self.action_tx.clone();
                tokio::spawn(async move {
                    match devices.list(kind).await {
                        Ok(list) => { let _ = tx.send(Action::DevicesEnumerated(list)); }
                        Err(e) => { let _ = tx.send(Action::DeviceEnumerationFailed(e.to_string())); }
                    }
                });
            }
            Effect::ListWorktrees => {
                let wt = self.adapters.worktrees.clone();
                let tx = self.action_tx.clone();
                // repo_root: need access to config — effect_runner does NOT hold
                // AppState. Pass repo_root through Effect::ListWorktrees { repo_root }
                // OR have effect_runner clone the repo_root at construction time.
                // DECISION: extend Effect::ListWorktrees variant to carry repo_root: PathBuf.
                tokio::spawn(async move {
                    // ... match wt.list(repo_root).await ...
                });
            }
            // ... additional variants: RemoveWorktree, AddWorktree, AddWorktreeNewBranch,
            //     ListRemoteBranches, FetchJiraTitles, SaveJiraCache, SaveAndroidMode,
            //     RecordSimUsed, OpenInMultiplexer
        }
    }
}
```
