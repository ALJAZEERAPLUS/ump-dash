<objective>
Add a new domain predicate `CommandSpec::collision_policy() -> CollisionPolicy`
on the existing `CommandSpec` enum, with a sibling public enum
`CollisionPolicy { BlockNew, CancelPrevious }`. This is the type-driven
authority for TASK-05 collision handling: when `dispatch_command` detects
that a new task's `(discriminant, WorktreeId)` matches a running task on the
same worktree, it consults this predicate to decide whether to drop the new
dispatch (idempotent installs) or cancel the existing task and dispatch the
new one (builds / tests / runs).

Purpose: This plan is a pure domain change — zero infra, zero app, zero
tokio. Following the exact template of `is_cancellable()` (lines 119-137 of
`src/domain/command.rs`, added in Phase 13 / Plan 13-02). Phase 13's
predicate established the "type-driven cancellability surface" pattern; this
plan establishes the type-driven collision-policy surface.

Output: ~30 LOC added to `src/domain/command.rs` (enum + impl method +
inline tests). All `CommandSpec` variants must be covered — adding a new
variant to `CommandSpec` after this plan will produce a compile error in the
test `collision_policy_covers_every_variant` until the maintainer assigns a
policy (same drift-guard mechanism `is_cancellable()` uses).
</objective>
