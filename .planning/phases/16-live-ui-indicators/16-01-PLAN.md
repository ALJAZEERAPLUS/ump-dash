<objective>
Create `src/ui/indicators.rs` — a pure, terminal-free UI helper module providing the three display primitives the row renderer (Plan 16-02) consumes: a 6-frame spinner glyph selector, an elapsed-time formatter, and an exhaustive `CommandSpec → short label` lookup. Register the module in `src/ui/mod.rs`.

This is the interface-first plan. It defines the contracts (function signatures, the `SPINNER_FRAMES` const, the swappable-fallback design) that Plan 16-02 imports and wires into `render_worktree_table`. All logic here is a pure function of `(Duration)` or `(&CommandSpec)` — no I/O, no `AppState`, no `Instant::now()`, no `crate::infra::` imports — so G-02 (`ui/` imports zero infra) is trivially satisfied and every behavior is unit-testable without a terminal.

Purpose: Satisfies the helper half of UI-02 (spinner frame formula + per-variant label) and UI-03 (elapsed format). Isolating these as pure functions means the only thing Plan 16-02 cannot unit-test (terminal glyph width) is cleanly separated from everything that can.

Output: `src/ui/indicators.rs` (helpers + co-located `#[cfg(test)] mod tests`), one-line registration in `src/ui/mod.rs`.
</objective>
