# Quick Task 260623-k7w: Add existing-branch picker to worktree checkout new branch command

## Goal

When the user runs the git checkout new-branch command (`g>c`), show the same branch picker used by the new-worktree branch flow so the user can choose the base branch, then type the new branch name.

## Tasks

1. Add a regression test for the `GitCheckoutNew` flow:
   - `CommandRun(GitCheckoutNew)` should request remote branches instead of opening text input immediately.
   - confirming a branch should open the new branch name text input for checkout-new mode.
   - submitting the name should dispatch `git checkout -b <new> <base>`.

2. Implement the flow in the TEA update layer:
   - reuse `Effect::ListRemoteBranches` and `ModalState::BranchPicker`.
   - distinguish checkout-new mode from new-worktree mode using existing modal-stack state.
   - preserve existing new-worktree branch picker behavior.

3. Update `CommandSpec::GitCheckoutNew` command data and call sites so the selected base branch can reach `to_argv()`.

- `cargo test app::dispatch_tests::git_checkout_new_submit_dispatches_with_selected_base_branch`
